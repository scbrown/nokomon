# Nokomon

A top-down pixel-art creature-collecting RPG built with Godot 4 and typed
GDScript. The project targets desktop and browser play through Godot's
Compatibility renderer.

## Open the project

Import `project.godot` in Godot 4, then run the main scene. The current project
foundation opens at a 16:9 reference resolution and scales its 2D interface with
the window.

Nokomon is a top-down, creature-collecting RPG about exploration, companionship,
and the difficult balance between human prosperity and the needs of the natural
world.

The current product vision is documented in [VISION.md](VISION.md).
